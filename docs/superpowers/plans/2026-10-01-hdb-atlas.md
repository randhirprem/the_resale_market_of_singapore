# HDB Atlas Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Deliver a working cyberpunk dashboard for all supplied HDB resale transactions.
**Architecture:** React/Vite frontend with Leaflet and Recharts; Python standard-library HTTP API and indexed SQLite database.
**Tech Stack:** React, Vite, Leaflet, Recharts, Python 3, SQLite.
**Spec:** ../specs/2026-10-01-hdb-atlas-design.md. User supersedes light styling with cyberpunk styling and explicitly requests implementation now.

## Global Constraints
Preserve all source CSVs and rows. Exact medians, nominal SGD, town-level map only. Default 2024; disclose data end date and 2012 date-basis transition. Localhost only.

## Review Focus
Empty selections must not create misleading zero prices. Invalid dates must fail with a clear error. Duplicate source rows must survive import. Pagination must reset on filter changes. Tile network failure must leave local map geometry usable.
